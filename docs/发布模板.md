## [X.Y.Z] - YYYY-MM-DD

### 💔 破坏性/行为变更

> 仅在存在签名破坏或行为变更时保留本段，否则整段删除。位置固定在版本标题之下。

- API 变更：`旧签名` → `新签名`，并给出迁移写法

```csharp
// 旧版本写法
// 新版本写法
```

- 行为变更：旧行为 → 新行为，写清影响范围（方言、档位、默认值）

### 变更要点

- 新增：一句话描述（新 API 写全签名）
- 修复：一句话描述症状与修复方式，写清受影响版本区间
- 性能：优化描述 + 实测数字与口径（方言/档位/批次），无实测写"机制改进，未基准"
- 依赖升级：包名 旧版本 → 新版本
- 验证：N 个测试全绿（Core N + SourceGen N + Integration N，含 PG/MySQL 真库）

---

## 填写要求（提交前逐条核对）

| 项 | 要求 |
|----|------|
| 版本标题 | `## [X.Y.Z] - YYYY-MM-DD`，日期等于 tag 提交日 |
| 破坏性 | 签名破坏或行为变更必须有 `### 💔` 段，其余条目不得混入该段 |
| 条目粒度 | 一句一个事实，禁止"修复了若干问题"式概括 |
| 数字 | 全部来自本次实测，禁止沿用上一版 |
| 范围 | 只写包消费者可见的变化，基准工具与质量脚本不进版本段 |
| 格式校验 | `dotnet run --file scripts/pre-release-check.cs -- <新版本>` 必须全绿 |

格式细则见 [发布变更日志规范](发布变更日志规范.md)；版本号语义见 [发布规范](发布规范.md) §1.2。
