# PalORM 性能报告模板（v1.0，2026-11-02 定稿）

> **用途**：每次全量性能测试（`PerfCli full`）后交付性能报告的固定骨架。数据章节由 `PerfCli report` 自动产出，人工只写 §0、§3、§4、§8。
> **参照实例**：`docs/性能全量报告-2026-11-02.md`（508 行，8+1 单源首版）。
> **口径定义**：`docs/性能基准规范.md`；七节交付形态（对外汇报消息）：`docs/性能汇报样例-2026-11-02.md`。

## 使用步骤

```bash
# 1. 全量跑测（约 40 分钟：微基准 + PerfHub + CrossBench + 门禁 + 报告）
dotnet run --project tools/PalORM.PerfCli -c Release -- full

# 2. 只用历史数据重建报告（不跑测试）
dotnet run --project tools/PalORM.PerfCli -c Release -- report

# 3. 产物
#    bench/reports/perf-report-<时间戳>.md（自动生成的报告主体）
```

产出后按本模板补写 §0、§3、§4、§8，再按文末清单核对。

## §1 数据源与新鲜度（自动）

`PerfCli report` 产出，两栏分列横评批与回归批。**禁止把两份数据的数字放进同一行比较**。

## §2 12 维总览（自动）

每维一行：状态 + 本轮数据来源。未测维度如实列缺口。

## §3 异常判读（半自动）

表七（报告尾）机械列出 P/ADO ≥3.0 或 ≤0.5 的格，人工逐项写判读，四段式：症状、证据链、判定、处置。

```md
- **<组> <操作>（<方言> <倍数>×）**：<机制判断>；<是否为既有形态/回归>；处置见 §8。
- **<组> PG 事务族（0.14~0.16×）**：<快于基准的解释>，基准健全性待核，两方言同向。
```

要点：未复测不归因；比值失真时先看基准列自身的批内散布。

## §5 回归视图（自动）

BDN 27 项判定、并发负载、大结果集内存、跨夹具登记（最近 20 批）、关键项速览（各夹具最近一批的 PalORM 臂）。

## §6 8+1 组横评（自动）

- 结论面板：可比格数、胜场榜、PalORM 中位比与区间。
- 表一 CRUD、表二 批量、表三 事务、表五 补充读：12 列固定，每格四行 `时延 / 时延百分比 / 内存 / 内存百分比`，基准格第二、四行为 `[1.00]`。
- 表四 跨方言精确比值（全 17 操作，裸倍数）。
- 表六 覆盖账本（每组每方言有值点数 / 理论点数）。
- 表七 异常判读（≥3.0× 或 ≤0.5×）。

## §7 指标定义与判读纪律（自动图例 + 规范引用）

色标六档、📌 阈值（≥1.50 或 ≤0.67）、⚠ 判别力弱（任一 ErrorRatio > 5%）、判据层级（绝对耗时 > 同批基准 > 同批比值 > 跨轮比值）。
