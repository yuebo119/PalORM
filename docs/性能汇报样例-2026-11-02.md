## 3. 异常判读（≥3.0× 或 ≤0.5× ADO）

**核心原则**：比值 = 该组时延 ÷ 同批 ADO 地板。地板自身漂移时比值失真，判据层级为绝对耗时 > 同批地板 > 同批比值 > 跨轮比值（B100）。

**当批判读**：

- **SqlSugar UpsertBatch（SQLite 107.5× / MySQL 35.8×）**：Storageable 分页形态仍呈二次方增长，较 11-01 批 809× 已收敛 7.5 倍，仍是横评表最大离群。处置见 §7。
- **EF Core SQLite Insert（66.5~67.2×）**：每操作 DbContext + SaveChanges 的固有成本，与 ADO 单条 INSERT 不同构，属形态差。
- **Dapper.AOT SQLite UpsertBatch（45.7×）**：AOT 生成器对批量 upsert 走逐条路径，非本轮回归。
- **EF Core PG 事务族（0.14~0.16×）**：EF 事务内批量提交路径快于 ADO 逐条，地板健全性待核，两方言同向。

## 6. 指标定义与判读纪律（附录）

- **时延**：两遍反序批内 Average 的 `MedianNs` 均值，单位 µs / ms；**分配**：`AllocatedBytesPerOp` 均值，1024 进制。
- **比值**：该组 ÷ 同方言同操作同档 ADO 地板；色标六档（🟢 ≤−30% · 🟩 −29%~−10% · 🔹 −9%~−1% · ⚪ 0% · 🔸 +1%~+9% · 🟧 +10%~+29% · 🟥 ≥+30%）。
- **📌**：比值 ≥1.50 或 ≤0.67，标记待看（劣化与远优两个方向都要过目），不是告警。
- **⚠**：该格任一侧 ErrorRatio（标准误/均值）> 5%，判别力弱。
- **判据层级**：绝对耗时 > 同批地板 > 同批比值 > 跨轮比值（B100）；未复测不归因；负向结论注明检索范围。
- **不可比声明**：横评与 PerfHub 回归不同夹具、不同批次，数字不互换；跨机绝对值不可比，同批比值可比。
