## P1-A：CI 性能门禁（工作量：3-4 小时）

**问题**：CI 无 benchmark job，性能回归只能靠手动发现

**方案**：新增 `.github/workflows/perf-gate.yml`

```yaml
# 每周定时 + 手动触发
# 跑 SQLite 基准（最稳定的环境）
# 与基线 JSON 对比，Median 回归 >10% 失败
```

**关键设计**：
- 只跑 SQLite 基准（消除外部 DB 环境噪声）
- 基线 JSON 存储在 `bench/baselines/v4.0.json`
- 回归判据：Median >10% 失败，Allocated >20% 警告
- PR 时可选触发（`[perf]` 标签）

---

## P1-B：基线持久化（工作量：1-2 小时）

**问题**：`BenchmarkDotNet.Artifacts/` 被 gitignored，版本间无法对比

**方案**：
1. 新增 `bench/baselines/` 目录（入 git）
2. 每次正式基准运行产出精简 JSON 基线
3. JSON 格式：
```json
{
  "version": "4.0.0",
  "date": "2026-07-22",
  "environment": { "cpu": "Ryzen 9 8945HX", "dotnet": "11.0.0-preview.6" },
  "benchmarks": [
    { "name": "PalORM_QueryAll", "median": 4.64, "unit": "ms", "allocated": "1.5MB" }
  ]
}
```
4. `run-benchmarks.sh` 增加 `--save-baseline` 选项

## P2-A：变异测试（工作量：2-3 小时）

**问题**：StrykerOutput 仅有 1 次历史运行，无法验证测试有效性

**方案**：用 Stryker.NET 做变异测试
- 变异 Core 项目的 CRUD 路径（最关键代码）
- 变异分数目标 >80%（业界标准）
- CI 可选触发（`[mutation]` 标签）

```bash
dotnet stryker --project PalORM.Core.csproj --mutate "src/PalORM.Core/DataSession*.cs"
```

**优先变异目标**：
1. `DataSession.Crud.cs`（CRUD 核心）
2. `MultiValueBulkInsert.cs`（批量骨架）
3. `QueryBuilderExtensions.cs`（查询执行管线）
4. `SessionOperationState.cs`（并发门禁）

---

## P2-B：方言差异断言测试（工作量：2-3 小时）

**问题**：PG RETURNING vs MySQL LAST_INSERT_ID、UPSERT 方言差异无专项断言

**方案**：新增 `test/PalORM.Integration.Tests/DialectTests.cs`

| 测试 | PG 路径 | MySQL 路径 | 断言 |
|------|---------|-----------|------|
| Insert 回填 | RETURNING 物化整行 | LAST_INSERT_ID + 回填 | ID 正确 + 其他字段保持 |
| Upsert 冲突 | ON CONFLICT DO UPDATE | ON DUPLICATE KEY UPDATE | 版本字段不丢 |
| Bulk 策略 | Binary COPY | 多值 INSERT | 行数正确 |
| LIMIT OFFSET | OFFSET 语法 | LIMIT skip,take | 结果集正确 |
| 类型映射 | TIMESTAMPTZ | DATETIME | 时区一致 |

## P2-C：纯速度基准（无 MemoryDiagnoser）（工作量：1 小时）

**问题**：MemoryDiagnoser 每次 `GC.Collect + WaitForPendingFinalizers` 阻碍 JIT 内联

**方案**：新增 `SqliteBenchmarksNoDiagnoser` 类（纯速度，无分配追踪）
- 与 MemoryDiagnoser 版本交叉验证
- 如果纯速度版本显著快（>5%），说明 MemoryDiagnoser 干扰了测量

```csharp
[SimpleJob(launchCount: 3, warmupCount: 5, iterationCount: 10)]
// 注意：无 [MemoryDiagnoser]
public class SqliteSpeedBenchmarks { ... }
```
