## 1. 结论

- **当前全量墙钟**：19m34s 与 19m37s，中位 19m35s（1175.5s）[事实]。作战卡的 18m20s 是交错读改造前的批次；交错读的 discarded pass 单独占 76s，解释了 86s 差额的绝大部分。
- **结构**：PerfHub 占 70.9%（834s / 1175.5s），微基准步占 28.5%（334s），门禁与统一报告合计 4s，`Report.Build` 解析 359 份历史 JSON 仅 **0.46s**。
- **PerfHub 内部**：计时循环 406s（34.5% of full）、预热 247s（21.0%）、重置/播种 67s（5.7%）、交错读 discarded pass 76s（6.5%）、夹具固定 8s、未归因 4.8s（0.6%）。**预热与计时合计 653s，占全量 55.5%。**
- **保守方案上限**：T2（采样预算最激进减半）+ T5（固定开销）合计可省 **217s + ≤30s ≈ 4.1 分钟** → 约 **15.5 分钟** [推断]。达不到作战卡的 ≤11 分钟，差距约 4.5 分钟；也达不到按本轮基线折算的 60% 线（11m45s），差距约 3.7 分钟。
- **达到 ≤11 分钟只有一条有实测余量的路**：T4 三方言并行（预测 834s → 约 314s，省 8.7 分钟）[推断]。它改运行模型，需 ADR、顺序 vs 并行 A/A 等价性证明、并发测量隔离；等价性不成立时退回 T1/T9 频率分层（需用户批准覆盖与节奏变化，属红线 #3/§10.1 停止项）。

## 3. 三类成本归因

| 类别 | 内容 | 实测 | 占全量 | 处置原则 |

> 三类之和 1242s > 1175.5s，因为 BDN 同时被计入"编排固定"与"策略"（它是固定成本，也是覆盖策略）；按互斥口径：A 663s、B 199s、C 313s（1175.5 − 663 − 199）。

## 6. 为什么安全（本轮只加插桩）

- **插桩开销 A/B**：同一参数（SQLite/2000，非 quick）4 批交替 off→on→on→off。运行耗时 103s / 101s / 103s / 102s；逐项墙钟合计 96.2s / 93.7s / 96.5s / 95.2s。差异 ≤1%，方向不一致，**低于作战卡 2% 阈值** [事实]。插桩形态：每阶段一次 `Stopwatch.GetTimestamp()`，每项一个计时对象，均在计时循环之外。
- **测量语义未变**：history JSON、结果库信封、门禁阈值、预热/迭代/预 GC 规则逐字未改；计时数据写独立旁车 `perf-timing-*.json`。
- **两次全量一致性**：总墙钟 1174s vs 1177s（+0.3%）；PerfHub 834s vs 828s（−0.7%）；阶段占比最大差 0.6pp。
- **最慢 20 项复现性**：18/20 在 ±10% 内 [事实]；两项越界均为 MySQL/20000/BulkInsert（ADO 6.49→4.91s，r=1.32；PalORM 6.35→7.16s，r=0.89）。根因：自适应迭代数由单次 probe 决定（ADO 两轮 probe 0.06s vs 0.09s → 70 vs 42 轮），属既有的采样设计方差，不是插桩引入。**这条同时是 T2 的前置风险：预算减半会把部分慢项推向 3 轮下限**。
- **门禁**：两轮全量的 BDN 27/27 与结果库库门禁均 OK（`[3/5]` 退出码 0）。
- **未做**（模式 A 边界）：变异探针、覆盖对账、基线重录、新快线验证——这些属于阶段 2-5，需在实施时按作战卡 §8 补齐。

## 7. 风险、回滚与后续

- **回滚**：插桩由 `PALORM_PERFHUB_TIMING=1` 控制，默认关闭；关闭时只多一次布尔判断，不写旁车、不改进度输出之外的任何文件。旁车在 gitignored 的 `bench/reports/`，删除即恢复。
- **风险**：本轮没有改任何默认行为，所以没有产品/门禁风险；唯一的风险是"把阶段 0 的数字当成可引用性能数字"——报告页头已声明它只用于时间分解。
- **下一步（需用户裁决）**：
  1. 若坚持 ≤11 分钟：批准 T4a 的 ADR 与并行等价性验证（顺序 vs 并行 A/A、逐项中位数 ≤5% 偏移、并发段隔离、独立结果文件与一次合并）。
  2. 若可接受"日常快线 + 定期全量"：批准 T1 的 L0 覆盖映射与历史回放方案（红线 #3 要求显式批准覆盖变化）。
  3. 无论哪条，T2 的噪声曲线是共同前置（3 配置 × 3 轮 A/A，输出中位数 CI 与 A/A 散布）。
  4. T5a（报告解析）与 T6（CI 拆分）可以独立推进，互不阻塞。
