## 1. 架构与设计 (STD-ARCH)

> 来源：Phase 1 (坑 1-15) + 架构层面避开 (坑 91-100)

| ID | 规则 | 必须/应当/建议 | 坑编号 | 检查方式 |
|:--|------|:--:|:--:|------|
| STD-ARCH-001 | QueryBuilder 链式无状态泄漏 — 每次 `From<T>()` 新建 Builder，条件不跨查询残留 | 必须 | #1 | 单元测试：两次 From<T> 验证无条件残留 |
| STD-ARCH-002 | 零外部 ORM 依赖 — 不引用 Dapper/EF Core/NHibernate 等第三方 ORM NuGet 包 | 必须 | #2, #7, #11 | `grep "Dapper\|EntityFramework\|NHibernate" src/*.csproj` |
| STD-ARCH-003 | DataSession using-scoped 无状态 — 用完即弃，禁止长生命周期 ISession/DbContext | 必须 | #4, #6, #91, #93 | 代码审查：无 ISession 字段/属性 |
| STD-ARCH-004 | 不做 Lazy Loading — 无 virtual 导航属性，关联数据通过 Include 显式加载 | 必须 | #5, #92 | `grep "virtual" src/ --include="*.cs"` 验证零命中 |
| STD-ARCH-005 | 不做 Change Tracker — DataSession 无状态，无 DetectChanges/SaveChanges 累加 | 必须 | #6, #93 | DataSession 无 ChangeTracker 相关 API |
| STD-ARCH-006 | 零公开全局可变状态 — 配置只存在于 DbOptions 实例；编译期实体元数据只能经 `Register(RegistryFragment)` 在锁内构造并一次发布不可变快照，外部只读 | 必须 | #14, #27, #45, #98 | 代码审查：无 ISession 字段/属性；门禁 G12（本地 .ai/scripts/gate-check.sh） |
| STD-ARCH-007 | 不做 LINQ 翻译引擎 — 不依赖 Expression.Compile() 将 LINQ 表达式转 SQL | 必须 | #7, #15 | 无 ExpressionVisitor/IQueryable 实现 |
| STD-ARCH-008 | 不做继承映射 (TPH/TPT/STI) — 每个实体独立 [Table] 注解 | 必须 | #86/#95 | 代码审查：无 Discriminator 列 |
| STD-ARCH-009 | 不做 Assembly Scanning — 实体通过 [Table] 注解编译时已知，不运行时扫描 | 必须 | #94 | 无 `Assembly.GetTypes()` 调用 |
| STD-ARCH-010 | Provider 独立不跨引用 — Sqlite/PostgreSql/MySql 各自独立，禁止互引 | 必须 | #13 | 检查 csproj：ProviderA 不引用 ProviderB |
| STD-ARCH-011 | Core 层零外部依赖 — 仅 BCL + ADO.NET，禁止第三方库引用 | 必须 | #9, #12 | `grep "using Dapper\|using Newtonsoft" src/PalORM.Core/` |
| STD-ARCH-012 | 明确不做列表文档化 — 变更追踪/Lazy Loading/LINQ 翻译/继承映射等明确排除 | 应当 | 全部架构避开 | 对照 docs/架构设计.md §1.5 |
| STD-ARCH-013 | 内置缓存容量上限 — 如未来添加查询缓存，必须设过期时间+容量上限，禁止无限增长静态字典 | 必须 | #7, #131-#135 | 缓存实现 → 验证 LRU 上限 + TTL |

## 3. SQL 安全与注入防御 (STD-SEC)

> 来源：Phase 2 + Phase 6 (坑 25, 26, 81-90)

| ID | 规则 | 必须/应当/建议 | 坑编号 | 检查方式 |
|:--|------|:--:|:--:|------|
| STD-SEC-001 | FormattableString 默认参数化 — 所有 SQL 使用 `$"..."` 插值，禁止 string.Format 拼接 | 必须 | #25, #26, #81, #97 | `grep "string\.Format.*SELECT\|string\.Format.*INSERT" src/` → 零 |
| STD-SEC-002 | ID 值从不裸拼 SQL — 始终 `@p0` 参数化，防止二阶注入 | 必须 | #26 | 审计所有 ID→SQL 路径 |
| STD-SEC-003 | 动态 ORDER BY / GROUP BY — 使用 `A17 Literal` 白名单校验，拒绝非白名单值 | 必须 | #81 | SQL 注入测试 ORDER BY |
| STD-SEC-004 | 错误消息不泄露 SQL/参数 — A16 Interceptor 生产模式隐藏，开发模式显示 | 必须 | #83 | 错误消息审核：无完整 SQL |
| STD-SEC-005 | 连接串不在代码中 — DbOptions 支持环境变量/KeyVault，禁止硬编码 | 必须 | #84, #144, #282 | `grep "Password=\|pwd=\|connectionString=\" src/` → 零 |
| STD-SEC-006 | 不做实体绑定 (Mass Assignment) — DTO 与 ORM 实体分离，无 `Update(entity)` API | 必须 | #85 | 无实体直接绑定 API |
| STD-SEC-007 | 聚合函数参数化 — Count/Sum/Avg 等聚合函数使用 FormattableString，防 CVE-2026-26198 | 必须 | #143 | SQL 注入测试聚合函数 |
| STD-SEC-008 | TLS 加密默认开启 — sslmode=require，除非显式 opt-out | 必须 | #90, #280 | 连接加密验证 |
| STD-SEC-009 | 错误消息不泄露 PII — A16 Interceptor 脱敏敏感字段 | 必须 | #77, #147 | 日志审核：无 PII |
| STD-SEC-010 | 物理删除需显式调用 — `[SoftDelete]` 物理删除 `Delete(physical:true)` | 应当 | #88 | 物理删除 API 存在 |
