# 第一部分：定位与架构

## 一、命名与定位

**PalORM** — 面向严格 Native AOT 的微 ORM。FormattableString 编译时参数化 + IIncrementalGenerator + struct QueryBuilder；SQLite 与 NuGet consumer 原生运行已验证，PostgreSQL/MySQL 服务容器运行待 CI。

### 对标矩阵

| 维度 | Dapper | EF Core | PalORM |
|------|:--:|:--:|:--:|
| 定位 | 微 ORM | 全功能 ORM | AOT 微 ORM |
| API | ~40 | 200+ | **112 已实现** |
| 参数化 | 匿名对象(反射) | LINQ 表达式 | **FormattableString(编译时)** |
| AOT | ❌ | ❌ | **SQLite 已运行；PG/MySQL 待 CI** |
| 源生成器 | Dapper.AOT | Precompiled | **RowFactory+CommandFactory+SqlFile+SqlTemplate** |
| QueryBuilder | — | — | **struct（值类型）** |
| 依赖 | Dapper | EF Core | 3 Provider NuGet + 1 CodeAnalysis(PrivateAssets=all) |

### 明确不做

| 不做 | 原因 |
|------|------|
| Change Tracker | 状态追踪=GC 压力 |
| Lazy Loading | 线程池饥饿 |
| LINQ 翻译引擎 | Expression.Compile()→AOT 不可用 |
| Assembly Scanning | 运行时反射→AOT 不兼容 |
| 全局可变状态 | 测试间污染 |
| Expression 全局过滤 | `WithFilter(Expression)` 已移除，用 `[SoftDelete]`/`Where(FormattableString)` 替代 |

## 二、架构设计

### 2.1 编译时→运行时数据流

```
┌─ 编译时 ─────────────────────────────────────────────┐
│ [Table("orders")] public partial class Order { ... } │
│   ↓                                                   │
│ PalORMGenerator (IIncrementalGenerator)               │
│   ForAttributeWithMetadataName("PalORM.TableAttribute")│
│   → RowFactory / CommandFactory / Migration / Registry│
│   → SqlFile ([SqlFile]特性替代 AdditionalTexts)       │
│   → SqlTemplate (FormattableString常量)               │
│ 输出: obj/Generated/PalORM.SourceGen/*.g.cs           │
└───────────────────────────────────────────────────────┘
   ↓
┌─ 运行时 ─────────────────────────────────────────────┐
│ var db = await DataSession<SqliteProvider>.CreateAsync│
│ var orders = await db.From<Order>()                   │
│     .Where($"status = {"active"}")                    │
│     .ToListAsync(ct);                                 │
│                                                       │
│ 内部: struct QueryBuilder 链式收集 → BuildSql(VSB)    │
│ → DbCommand → RowFactory.Read(DbDataReader)           │
│ → 零反射 · struct(值类型)                           │
└───────────────────────────────────────────────────────┘
```

### 2.2 源生成器实际结构

**PalORMGenerator.cs** — 注册 6 条 pipeline:

```csharp
[Generator]
public sealed class PalORMGenerator : IIncrementalGenerator
{
    public void Initialize(IncrementalGeneratorInitializationContext context)
    {
        var tableModels = context.SyntaxProvider
            .ForAttributeWithMetadataName("PalORM.TableAttribute",
                predicate: static (node, _) => node is ClassDeclarationSyntax,
                transform: static (ctx, _) => TableModel.FromContext(ctx))
            .Where(static m => m is not null);

        context.RegisterSourceOutput(tableModels, RowFactory);
        context.RegisterSourceOutput(tableModels, TypeMapper);
        context.RegisterSourceOutput(tableModels, CommandFactory);
        context.RegisterSourceOutput(tableModels, Migration);
        context.RegisterSourceOutput(tableModels.Collect(), Registry); // +CrudMetadatas+SetId

        // SqlFile: [SqlFile("path.sql")] 特性
        var sqlFiles = context.SyntaxProvider
            .ForAttributeWithMetadataName("PalORM.SqlFileAttribute", ...);
        context.RegisterSourceOutput(sqlFiles, SqlFile);

        // SqlTemplate: [SqlTemplate("name")]
        var sqlTemplates = context.SyntaxProvider
            .ForAttributeWithMetadataName("PalORM.SqlTemplateAttribute", ...);
        context.RegisterSourceOutput(sqlTemplates, SqlTemplate);
    }
}
```

**生成产物**（每个实体，obj/Generated/ 目录下）:

| 文件 | 内容 |
|------|------|
| `{Type}_RowFactory.g.cs` | `IRowFactory<T>.Read(DbDataReader)`；仅生成具备明确读取与 DDL 契约的 CLR 类型，`short`/`byte`/`char` 显式映射，`byte[]`/`TimeSpan` 需先配置 Converter |
| `{Type}_CommandFactory.g.cs` | INSERT/UPSERT/UPDATE/DELETE SQL 与独立 binder、默认键判断、版本推进、仅自增 int/long 的 SetId；对象型 OwnedJson 缓存强类型 `JsonTypeInfo<T>` |
| `{Type}_Migration.g.cs` | CREATE TABLE DDL |
| `{Type}_TypeMapper.g.cs` | 自定义类型↔DB (DateTimeOffset/Guid) |
| `PalORM_Registry.g.cs` | ModuleInitializer 构造完整 `RegistryFragment`，包含 InsertColumns、UpsertColumns、PropertyToColumn 与 EntityFeatures；运行时在锁内合并并一次发布完整不可变状态，公开注册表仅提供只读视图，不扫描程序集或读取运行时 Attribute |

### 2.3 运行时核心

**DataSession<TProvider>** — using-scoped，无状态:

```csharp
public sealed class DataSession<TProvider> : IAsyncDisposable where TProvider : IDbProvider
{
    // 工厂方法 → 自动 Open + 重试 + SQLite PRAGMA
    public static async Task<DataSession<TProvider>> CreateAsync(DbOptions options, CancellationToken ct);

    // 查询入口 → struct QueryBuilder（值类型）
    public QueryBuilder<T> From<T>() where T : class, new();

    // CRUD → CrudMetadatas 单次 TryGetValue
    public ValueTask<T> InsertAsync<T>(T entity, CancellationToken ct);       // PG/SQLite: RETURNING; MySQL: INSERT+LAST_INSERT_ID 单次往返
    public ValueTask<int> UpdateAsync<T>(T entity, CancellationToken ct);
    public ValueTask<int> DeleteAsync<T>(object key, CancellationToken ct);

    // 默认自增键走 Insert；非默认键走源生成 UPSERT
    public ValueTask<T> SaveAsync<T>(T entity, CancellationToken ct);
    // 单一 int/long [ConcurrencyCheck] 使用原子 version + 1；0 行抛 ConcurrencyConflictException

    // 批量 → 复用 active transaction；自有事务失败时回滚且不覆盖主异常
    public ValueTask<long> BulkInsertAsync<T>(IReadOnlyList<T> entities, int batchSize, CancellationToken ct);
    public ValueTask<long> BulkDeleteAsync<T>(IReadOnlyList<object> keys, CancellationToken ct);
    public ValueTask<long> BulkUpdateAsync<T>(IReadOnlyList<T> entities, CancellationToken ct);
    public ValueTask<long> BulkMergeAsync<T>(IReadOnlyList<T> entities, CancellationToken ct);

    // 事务 → 函数式(WithTransaction) + 显式(UseTransaction) 双模式
    // callback 内顺序操作共享事务；嵌套事务和其他逻辑流加入会明确失败
    public ValueTask WithTransaction(Func<CancellationToken, Task> action, ...);
    public DataSession<TProvider> UseTransaction(DbTransaction? tran);

    // 直查
    public ValueTask<List<T>> QueryAsync<T>(FormattableString sql, CancellationToken ct);
    public ValueTask<T> QueryFirstAsync<T>(FormattableString sql, CancellationToken ct);
    public ValueTask<T> QuerySingleAsync<T>(FormattableString sql, CancellationToken ct);
    public ValueTask<T?> ScalarAsync<T>(FormattableString sql, CancellationToken ct);
    public ValueTask<int> ExecuteAsync(FormattableString sql, CancellationToken ct);
    public IAsyncEnumerable<T> QueryAsyncEnumerable<T>(FormattableString sql, ...);

    // 聚合
    public ValueTask<long> CountAsync<T>(FormattableString? where, CancellationToken ct);
    public ValueTask<decimal> SumAsync<T>(FormattableString expression, CancellationToken ct);

    // 配置
    public DataSession<TProvider> WithTimeout(TimeSpan);
    public DataSession<TProvider> WithRetry(int, Func<int,TimeSpan>?);
    public DataSession<TProvider> WithCircuitBreaker(int, TimeSpan);
    public DataSession<TProvider> AddInterceptor(IQueryInterceptor);
    public DataSession<TProvider> WithTenant(object tenantId);
    public DataSession<TProvider> IgnoreFilters();
    
    // 健康检查 + 逃生舱 + 迁移
    public ValueTask<HealthResult> HealthCheckAsync(CancellationToken ct);
    public DbConnection GetRawConnection();
    public ValueTask MigrateAsync(CancellationToken ct);
    public StoredProcBuilder StoredProc(string name);
}
```

**会话并发生命周期** — `SessionOperationState` 是 DataSession、QueryBuilder、Bulk、StoredProc 与 GridReader 共用的单一状态，并在同一锁内管理当前事务。普通执行入口非阻塞获取 operation lease；重叠调用 fail-fast。GridReader 把 lease 持有到释放；函数式事务会在 commit/rollback 前自动释放 callback 遗留的 GridReader。`WithTransaction` 另持有逻辑 flow 完成信号，Dispose 会等待命令和事务 flow 后再关闭连接。组合管线只通过内部 capability 顺序重入，不依赖可传播到派生任务的隐式 operation owner。

**QueryBuilder<T>** — struct（值类型），执行方法在 QueryBuilderExtensions:

```csharp
public struct QueryBuilder<T> where T : class, new()
{
    // 链式构建（返回 struct 副本，共享 List 引用）
    public QueryBuilder<T> Where(FormattableString clause);    // 自动 BindArgs
    public QueryBuilder<T> OrWhere(FormattableString clause);
    public QueryBuilder<T> OrderBy<TKey>(Expression<Func<T,TKey>>, bool desc);
    public QueryBuilder<T> ThenBy<TKey>(Expression<Func<T,TKey>>, bool desc);
    public QueryBuilder<T> Select(params Expression<Func<T,object?>>[]);
    public QueryBuilder<T> WhereIn<TValue>(Expression<Func<T,TValue>>, IEnumerable<TValue>);     // 自动500分批
    public QueryBuilder<T> WhereNotIn<TValue>(Expression<Func<T,TValue>>, IEnumerable<TValue>);
    public QueryBuilder<T> InnerJoin<TJoin>(FormattableString);
    public QueryBuilder<T> LeftJoin<TJoin>(FormattableString);
    public QueryBuilder<T> RightJoin<TJoin>(FormattableString);
    public QueryBuilder<T> GroupBy(Expression<Func<T,object?>>);
    public QueryBuilder<T> Having(FormattableString);
    public QueryBuilder<T> Set<TValue>(Expression<Func<T,TValue>>, TValue value);
    public QueryBuilder<T> Include<TChild>(...);
    public QueryBuilder<T> ThenInclude<TGrandChild,TParent>(grandChildKey,parentKey);
    // 单参数 ThenInclude 无法表达 JOIN 两端，已弃用并明确失败
    public QueryBuilder<T> With(string cteName, FormattableString subquery);  // CTE
    public QueryBuilder<T> UnsafeWindowOver(string func, string over);         // 可信原始SQL结构，追加到SELECT列
    public QueryBuilder<T> AsSplitQuery();                                     // 只构建根查询，不装配导航对象
    public QueryBuilder<T> ForRead();                                          // 记录读路由，执行时租用连接
    public QueryBuilder<T> ForWrite();                                         // 强制主连接
    // DataSession.ForRead/ForWrite 仅作兼容弃用；新代码不得使用
    public QueryBuilder<T> ForUpdate(bool skipLocked=false);
    public QueryBuilder<T> ForShare();
    public QueryBuilder<T> Raw(string literal);
    public QueryBuilder<T> Tag(string name);
    public QueryBuilder<T> TagWithCaller([CallerMemberName]...);
    public QueryBuilder<T> Take(int n);
    public QueryBuilder<T> Skip(int n);
    public QueryBuilder<T> AsPrepared();            // 参数绑定后调用 DbCommand.PrepareAsync
    public QueryBuilder<T> WithCache(string key, TimeSpan?);
    public QueryBuilder<T> WithCommandTimeout(int seconds);
    public QueryBuilder<T> WithTransaction(DbTransaction);
    public QueryBuilder<T> WithTracing();            // 静态 ActivitySource，低基数脱敏标签
    public QueryBuilder<T> WithMetrics(string name); // 静态 Meter；名称不进入标签
    public DryRunResult AsDryRun();

    // QueryClause 原子保存 kind、SQL 和参数；BuildSql 按语法类别输出
    internal string BuildSql();  // ValueStringBuilder ArrayPool 池化 512B 起租
}

// 执行方法 — 扩展方法, 避免 struct 装箱
public static class QueryBuilderExtensions
{
    public static ValueTask<List<T>> ToListAsync<T>(this QueryBuilder<T>, CancellationToken);
    public static ValueTask<T> FirstAsync<T>(this QueryBuilder<T>, CancellationToken);        // LIMIT 1统一执行管线
    public static ValueTask<T?> FirstOrDefaultAsync<T>(this QueryBuilder<T>, CancellationToken);
    public static ValueTask<T> SingleAsync<T>(this QueryBuilder<T>, CancellationToken);
    public static ValueTask<T?> SingleOrDefaultAsync<T>(this QueryBuilder<T>, CancellationToken);
    public static ValueTask<int> ExecuteNonQueryAsync<T>(this QueryBuilder<T>, CancellationToken);
    public static ValueTask<(List<T>,long)> ToPageAsync<T,TKey>(this QueryBuilder<T>, int, ...); // Keyset分页
    public static ValueTask<GridReader> QueryMultipleAsync<T>(this QueryBuilder<T>, FormattableString, CancellationToken);
}
```

**IDbProvider** — C# 11 static abstract interface:

```csharp
public interface IDbProvider
{
    static abstract string Name { get; }
    static abstract char ParameterPrefix { get; }
    static abstract SqlDialect Dialect { get; }
    static abstract DbConnection CreateConnection(string connectionString);
    static abstract DbConnection CreateConnection(string connectionString, DbOptions options);
    static abstract string QuoteIdentifier(string identifier);
    static abstract string QuoteQualifiedIdentifier(string? schema, string identifier);
    static abstract string GetLimitOffsetClause(int? limit, int? offset);
    static abstract bool SupportsReturningClause { get; }
    static abstract string GetParameterPlaceholder(int index);
    static abstract DbParameter CreateParameter(string name, object? value);
    static virtual bool IsTransient(Exception exception);
    static abstract int ConfigureSchemaCommand(DbCommand command, string tableName, string? schema = null);
    static abstract string CurrentTimestampExpression { get; }
    static virtual Task<long> BulkInsertAsync<T>(DbConnection, DbTransaction?, IReadOnlyList<T>, int, CancellationToken);
}
```

三 Provider:
- **PostgreSqlProvider**: Binary COPY + 参数化 `information_schema` Schema 命令 + Npgsql 池配置；使用 `DbException.IsTransient`
- **MySqlProvider**: batched INSERT + 引用后的 `SHOW COLUMNS` + MySqlConnector 池配置；使用 `DbException.IsTransient`
- **SqliteProvider**: batched INSERT（参数上限999自动节流）+ 引用后的 `PRAGMA table_info`；仅将 `SQLITE_BUSY/SQLITE_LOCKED` 判为瞬时故障；不支持的池配置明确失败

### 最优设计决策 (18项)

| # | 决策 | 收益 |
|---|------|------|
| 1 | QueryBuilder struct | From<T>() 值类型 |
| 2 | ValueStringBuilder | BuildSql 零 StringBuilder |
| 3 | 统一 Formattable SQL formatter | BCL 复合格式语法验证；DataSession、QueryBuilder、QueryMultiple 参数语义一致 |
| 4 | CrudMetadata 字典合并 | InsertAsync/UpdateAsync 单次 TryGetValue |
| 5 | UPSERT 单次往返 | SaveAsync ON CONFLICT DO UPDATE |
| 6 | MySQL InsertAsync 单次往返 | INSERT; SELECT LAST_INSERT_ID() |
| 7 | BulkInsert 委派 Provider | 三 Provider 共用源生成 InsertColumns/BindInsert；PG Binary COPY，MySQL/SQLite 多值 INSERT |
| 8 | BulkDelete IN 批量 | 500/批；Converter 主键走生成 binder；SoftDelete 更新 deleted_at |
| 9 | WhereIn 自动分批 500 | 防参数超限 |
| 10 | ForRead 懒加载读连接 | 读副本切换 |
| 11 | [SqlFile] Provider 分支 | -- @pg/@mysql/@sqlite/@all 编译时解析 |
| 12 | ~~BindInsertValues 委托~~ | 已删除（2026-07-17 ITM-113）：注册链零消费者，三 Provider BulkInsert 实际使用 rowCommand + BindInsert 提参 |
| 13 | JsonOptions 池化 | static readonly 每类型复用 |
| 14 | SplitQuery 标记式 | BuildSql 跳过 JOIN 不变异子句 |
| 15 | ConfigureSchemaCommand() | 三 Provider 各自配置安全命令与列名序号 |
| 16 | A1 WithFilter 移除 | Expression 编译 AOT 不安全 |
| 17 | static abstract TProvider | 零虚调用 |
| 18 | 编译期三方言 SQL/DDL | `CommandSqlByDialect` 与 `CreateTableSqlSet` 按静态 Provider 方言选择；标识符和类型语法不在运行时改写 |
