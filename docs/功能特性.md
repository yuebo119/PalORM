# PalORM 功能特性全景

> 本文由全量源码分析产出：`src/` 下 76 个源文件逐文件核对（约 2.8 万行），另含 `tools/PalORM.Scaffold`。每项特性落锚到文件与符号名；描述与代码不符时以代码为准，发现漂移欢迎提 issue。行号不写入本文（随提交漂移），定位请按符号名检索。

## 1. 总体定位与包结构

PalORM 是源生成器型微 ORM：SQL 构建、行物化、参数绑定、DDL 全部在编译期由 Roslyn 增量生成器产出，运行时零反射、零 Expression.Compile、零运行时代码生成，全链路 Native AOT 兼容。

- **编译期分发**：`IDbProvider` 是 C# 11 `static abstract` 接口（`src/PalORM.Core/IDbProvider.cs`），`DataSession<TProvider>` 经 JIT 泛型特化消除虚调用；Provider 是编译时常量，不做 DI 注册。
- **零依赖核心**：`PalORM.Core` 只依赖 BCL 与 ADO.NET 抽象，不引用任何第三方 NuGet 包。
- **6 个 NuGet 包**：`PalORM.Core`（运行时）、`PalORM.PostgreSql`、`PalORM.MySql`、`PalORM.Sqlite`（三方言）、`PalORM.SourceGen`（生成器 + 分析器）、`PalORM.Testing`（测试夹具）。

## 2. 实体映射注解（23 个，编译期元数据）

全部定义在 `src/PalORM.Core/Annotations.cs`，源生成器编译期读取，零运行时开销。

| 注解 | 级别 | 功能 |
|------|------|------|
| `[Table]` | 类 | 表名；`Schema`/`Database` 参数保留（PALORM011 拒绝使用） |
| `[SoftDelete]` | 类 | 软删除实体，查询自动过滤、删除自动转 UPDATE |
| `[TenantAware]` | 类 | 多租户列隔离 |
| `[Index]` | 类（可多次） | 复合索引声明，支持 `Unique` |
| `[Unique]` | 属性 | 唯一约束 |
| `[Column]` | 属性 | 列名；`Length`/`Precision`/`Scale`/`TypeName` 参与 DDL；`StoreAs` 枚举存储策略（int32/int64/字符串） |
| `[Key]` | 属性 | 主键，支持 long/int/short/byte/Guid/string/Ulid；`AutoIncrement=false` 表示应用侧赋值（雪花 ID 等） |
| `[NotMapped]` | 属性 | 排除非数据库属性 |
| `[IgnoreOnInsert]` | 属性 | INSERT 时跳过该列 |
| `[Required]` | 属性 | NOT NULL 约束 |
| `[ForeignKey]` | 属性 | 外键 + `OnDelete`（NoAction/Cascade/SetNull/Restrict），内联进 DDL |
| `[ConcurrencyCheck]` | 属性 | 乐观并发令牌（version 列） |
| `[Timestamp]` | 属性 | 数据库端自动时间戳列（DEFAULT CURRENT_TIMESTAMP） |
| `[Computed]` | 属性 | 计算列，`GENERATED ALWAYS AS (...) STORED`，写入命令排除、读取回填 |
| `[DefaultValue]` | 属性 | 数据库端 DEFAULT 表达式（DDL-only，插入路径不变） |
| `[Converter]` | 属性 | 编译期值转换器（`IValueConverter<TModel,TProvider>`），Ulid 等自定义类型通道 |
| `[OwnedJson]` | 属性 | JSON 列；对象形态必须配 System.Text.Json 源生成上下文（AOT 安全） |
| `[SensitiveData]` | 属性 | 日志脱敏掩码，贯穿拦截器与 MySQL BulkCopy 告警消息 |
| `[Projection]` | 类 | 只读投影 DTO（join/报表/聚合结果物化），不建表、不参与迁移 |
| `[SqlFile]` | 方法 | 外部 .sql 文件编译期嵌入（支持 `-- @pg/@mysql/@sqlite/@all` 条件段） |
| `[SqlTemplate]` | 方法 | SQL 模板提升为 `FormattableString` 常量，配合 `AsPrepared()` 预编译 |

配套枚举与接口：`StoreAs`、`DeleteAction`、`IValueConverter<TModel,TProvider>`。

## 3. 数据访问 API（DataSession 分部类）

会话生命周期与链式配置（`src/PalORM.Core/DataSession.cs`）：

- `CreateAsync`：建连 + 瞬时错误重试循环 + Provider 连接初始化钩子 + `SessionSetupSql` 会话级 SQL。
- `PreWarmAsync`：连接池预热（SQLite 直接返回）。
- 链式配置：`IgnoreFilters` / `WithTenant` / `WithIsolationLevel` / `WithTimeout` / `WithRetry` / `WithCircuitBreaker` / `AddInterceptor` / `UseTransaction`。
- `ForParallelReads`：并行只读作用域（上限 8 路并发读，连接池局部于作用域）。
- `CreateBatch`：DbBatch 打包（PG/MySQL）；`GetRawConnection` 原生连接逃生舱。
- `DisposeAsync`：等待活动操作/事务/读租约后有界释放。

CRUD 单行（`DataSession.Crud.cs`）：

- `InsertAsync`：按方言分派三种自增取回形态（PG/SQLite `RETURNING`、MySQL `LAST_INSERT_ID()`、无自增纯 INSERT）；唯一键冲突跨方言统一翻译为 `UniqueConstraintViolationException`。
- `UpdateAsync`：乐观锁实体自动 WHERE version 匹配，冲突抛 `ConcurrencyConflictException`；租户实体追加租户条件。
- `DeleteAsync`：软删实体自动转 `UPDATE deleted_at`，否则物理 DELETE。
- `GetAsync` / `GetAllAsync` / `SaveAsync`（默认主键走 Insert，否则单行 UPSERT；乐观锁实体明确拒绝）。
- `From<T>()`：进入查询构建器，自动附加软删除与租户默认过滤。

查询、聚合与分页（`DataSession.Query.cs` + `QueryBuilderExtensions.cs`）：

- 聚合五函数：`CountAsync` / `SumAsync` / `MaxAsync` / `MinAsync` / `AvgAsync`。
- 原生 SQL 族：`QueryAsync` / `QueryFirstAsync` / `QuerySingleAsync` / `ScalarAsync` / `ExecuteAsync` + 流式 `QueryAsyncEnumerable`（IAsyncEnumerable）；`FormattableString` 插值全部编译期参数化为 `@pN` 占位；首行列序校验（可经 `DbOptions.ValidateQueryColumnOrder` 关闭）。
- `ToPageAsync`：keyset 分页，COUNT 与页查询同事务一致性快照。
- `FirstAsync` / `FirstOrDefaultAsync` / `SingleAsync` / `SingleOrDefaultAsync` / `ToListAsync` / `ForEachAsync`（流式回调不物化）。

## 4. 查询构建器（QueryBuilder）

`src/PalORM.Core/QueryBuilder.cs`：struct 值类型构建器 + 静态扩展方法执行，链式调用零装箱；子句存持久化链表，位掩码 O(1) 判存。

- 条件：`Where` / `OrWhere` / `WhereIn` / `WhereNotIn`（500 键一批切分、参数总量守卫、空集恒假 `1=0`）。
- 排序分组：`OrderBy` / `OrderByDescending` / `ThenBy` / `GroupBy` / `Having`（表达式树解析成员名，经 `MemberResolver` 映射列名）。
- Join：`InnerJoin` / `LeftJoin` / `RightJoin`；`Include` / `ThenInclude` 外键 JOIN（只生成 JOIN 子句，不装配导航属性）。
- 分页：`Take` / `Skip`，LIMIT/OFFSET 形态按方言分派（MySQL `LIMIT n,m`、PG 裸 `OFFSET`、SQLite `LIMIT -1 OFFSET`）。
- 进阶子句：CTE `With`、窗口 `UnsafeWindowOver`、行锁 `ForUpdate(skipLocked)` / `ForShare`、`Raw` 原样片段（拒绝控制字符）、SQL 注释 `Tag` / `TagWithCaller`。
- 执行修饰符：`ForRead` / `ForWrite`（读写路由）、`WithCache(key, ttl)`、`AsPrepared`（PrepareAsync）、`WithTransaction`、`WithTracing` / `WithMetrics`、`WithCommandTimeout`、`AsSplitQuery`、`AsDryRun` / `ToSql`（SQL 与参数预览）。
- 查询结果缓存：同键命中浅拷贝返回，租户过滤查询缓存键自动加租户前缀（跨租户命中不可能）。

## 5. 批量操作（四入口，按方言与能力自动路由）

| API | SQL 形态 |
|-----|----------|
| `BulkInsertAsync` | PG：Npgsql Binary COPY（二进制定型行写入，`IBinaryRowSink` 值类型零装箱）；MySQL：驱动 `MySqlBulkCopy`（LOAD DATA LOCAL INFILE 线协议，服务端探测关闭时自动回退多值 INSERT）；SQLite 与兜底：多值 INSERT（`MultiValueBulkInsert`） |
| `BulkDeleteAsync` | PG 数组形态 `pk = ANY(@ids)`（能力探测）或 IN 占位符；软删实体自动转 UPDATE |
| `BulkUpdateAsync` / `BulkUpdateBatchAsync` | 单语句批量：PG `UPDATE ... FROM (VALUES)` 或 UNNEST 数组；MySQL `CASE WHEN` 或 `UPDATE ... JOIN (VALUES ROW(...))`（8.0.19+ 运行时版本探测 + 连接串键控 60s TTL 缓存）；SQLite 回退逐条 + DbBatch 100 条/往返打包 |
| `BulkMergeAsync` / `SeedAsync` | 批量 UPSERT：PG/SQLite `ON CONFLICT DO UPDATE`（含 RETURNING）、PG UNNEST 数组形态、MySQL `ON DUPLICATE KEY UPDATE`；UPSERT 冲突更新带租户护栏（PG/SQLite WHERE 追加、MySQL 逐赋值项包 IF） |

- 参数上限与分批单点在 `src/PalORM.Core/SqlLimits.cs`：SQLite 999 绑定参数、通用 65535、单批 5000 行。
- 命令与参数池跨批复用，批间只写参数 Value；自开事务遵从会话隔离级别。

## 6. 事务（DataSession.Transactions.cs + TransactionCleanup.cs）

- `BeginTransactionAsync`（默认取会话隔离级别）/ `WithTransaction`（含返回值泛型版）/ `WithTransactionRetry`：整事务按方言瞬时错误码重放（PG 40001/40P01、MySQL 1213/1205、SQLITE_BUSY/LOCKED），at-least-once 契约。
- Savepoint：`SavepointAsync` / `RollbackToAsync`；不支持嵌套事务（重复开启响亮抛异常）。
- 外部事务接入 `UseTransaction`：外部 Dispose 后续命令响亮失败，不静默自动提交。
- 提交安全：提交走超时窗口（超时抛带 `PalORM.InfrastructureTimeout` 标记的 TimeoutException）；提交失败后有界回滚裁决（服务端已终结事务则跳过回滚）；自增 ID 与乐观锁 version 回填延迟到 COMMIT 成功后回放（TX-004）。

## 7. Schema 迁移与健康检查（DataSession.Schema.cs）

- `MigrateAsync`：执行编译期生成的三方言 DDL；FK 依赖拓扑序（Kahn 算法）；重名对象幂等跳过并登记 `LastMigrationSkippedIndexes`；迁移后刷新统计（SQLite `PRAGMA optimize`、PG `ANALYZE`）。
- `ValidateSchemaAsync<T>`：读取数据库列集对照实体声明，返回缺失列清单。
- `HealthCheckAsync`：SELECT 1 探活；错误消息只透出异常类型名，防数据库拓扑泄露。

## 8. 原生 SQL、存储过程与多结果集

- `StoredProc`（`StoredProcBuilder.cs`）：存储过程调用，输入/输出参数、强类型输出取回、过程名白名单校验、single-use 契约。
- `QueryMultipleAsync` + `GridReader`（`GridReader.cs`）：多结果集顺序读取，列序校验、单活动读门禁。
- `[SqlFile]`（`SqlFileEmitter.cs`）：.sql 文件经 AdditionalFiles 进入增量管线（改 SQL 免 Rebuild），编译期嵌入为 C# 11 raw string 常量；路径安全校验（拒绝绝对路径与 `..` 遍历）；文件读取失败发 `[Obsolete(error)]` 占位，编译期暴露。
- `[SqlTemplate]`（`SqlTemplateEmitter.cs`）：方法体插值串提取为模板常量，执行时参数绑定后 `DbCommand.PrepareAsync`。

## 9. 源生成器与编译期诊断（src/PalORM.SourceGen/）

6 条增量管线（`PalORMGenerator.cs`）：实体表模型、Registry 聚合、投影、SqlFile、SqlTemplate、AutoTagging。

| Emitter | 产物 |
|---------|------|
| RowFactoryEmitter | 按列 ordinal 直读 `DbDataReader` 的静态物化委托：20+ CLR 类型 switch、可空三态处理、枚举 StoreAs 读写双路径、OwnedJson 经 `JsonSerializerContext` 反序列化 |
| CommandFactoryEmitter | 全 CRUD 参数绑定（建参 / 参数池只写 Value / DbType 一次初始化三形态）、PG COPY 定型行写入、UNNEST 逐列类型化数组、自增回填、乐观锁递增、Save 的 Insert/Update 判定 |
| RegistryEmitter | `[ModuleInitializer]` 注册 15 张 `FrozenDictionary`（不可变快照、单次 volatile 发布），运行时按 `typeof(T)` 查字典直调生成委托（`PalORM_Runtime.cs`） |
| MigrationEmitter | 三方言 CREATE TABLE / CREATE INDEX DDL 常量：类型映射、架构参数细化（TypeName > Precision > Length）、FK 内联、计算列与默认值 |
| ProjectionEmitter | 投影类型复用 RowFactory 管线，只注册物化委托，不生成写命令与 DDL |
| AutoTaggingEmitter | C# `[InterceptsLocation]` 拦截 9 个查询终态方法，SQL 自动注入「文件:行号 成员名」定位注释；opt-in 编译开关（`PalORMAutoTagging`），默认关闭零成本 |

- 方言裁剪：MSBuild 属性 `PalORMTargetDialects` 按方言裁剪 CRUD SQL 发射面（DDL 恒全发射三方言）。
- 编译期诊断 45 条（42 分析器 + 3 生成器，`PalORMAnalyzer.cs`）：覆盖缺 `[Key]`、复合主键、循环内 N+1、OwnedJson 缺 JsonSerializerContext、软删缺 deleted_at 列、租户列可空绕过隔离、并发令牌非法、索引声明冲突、SQL 标识符控制字符、投影互斥等建模错误，错误列表可跳转声明位置。

## 10. 横切能力

**软删除与多租户**：`From<T>()` 自动注入 `deleted_at IS NULL` 与 `tenant_id = @p`；默认过滤恒以 AND 前置且用户 OR 条件括组隔离，查询侧不可绕过；写路径（Update/Delete/批量删除/批量更新/UPSERT）全族追加租户条件；租户列在 Update/BulkUpdate 与 UPSERT 冲突更新中不在 SET 内（只能由 Insert 承载，防止跨租户搬移）；`IgnoreFilters()` 显式关闭且会话内无复位 API（管理查询请换会话）。

**弹性（零 Polly 依赖）**：`ResilienceExecutor` 重试 + 指数退避 + 随机抖动 + 超时 + 熔断一体化（`src/PalORM.Core/Resilience.cs`）；熔断三态状态机（Closed/Open/HalfOpen、半开单探针、探针槽位超时回收，`CircuitBreaker.cs`），Session / Process 两种作用域（Process 级按 Provider 与连接串跨会话共享，`CircuitBreakerRegistry.cs`）。

**读写分离**：`ReadConnectionString` 配置副本连接串；`ForRead()` / `readFromReplica` 路由副本；`ParallelReadScope` 并行只读。

**缓存五层**：查询结果缓存（`BoundedQueryCache`，默认 1024 条 + TTL，满时先清过期）、会话级 SQL 缓存（`DataSessionCache`，实体 × 方言键空间）、SQL 形状缓存（`SqlShapeCache`，同形状复用同一 SQL 文本实例）、参数名预建表（`ParameterNameCache`，`@p0`..`@p65535` 静态表零分配）、能力探测缓存（`CapabilityProbeCache`，连接串键控 TTL）。

**可观测**：OpenTelemetry 面 `ActivitySource` + `Meter`（指标 `palorm.query.executions` / `palorm.query.duration`，标签 db.system / db.operation / outcome，`PalORMMetrics.cs`）；`IQueryInterceptor` 三拦截点（OnBefore / OnAfter / OnOnError，优先级排序）；内置 `AuditInterceptor` 查询日志审计（参数与错误消息按 `[SensitiveData]` 掩码脱敏，可经 `AuditInterceptor.GetLoggableValue` 复用脱敏策略）。

**异常族**（`Exceptions.cs`）：`PalORMException` / `CircuitBreakerOpenException` / `ConcurrencyConflictException` / `UniqueConstraintViolationException`；基础设施超时统一为带 `Data["PalORM.InfrastructureTimeout"]` 标记的 `TimeoutException`，瞬时性以 `Data["PalORM.IsTransient"]` 标记表达。

## 11. 方言专属能力

| 方言 | 专属特性 |
|------|----------|
| PostgreSQL | Binary COPY 批量导入（定型行写入零装箱）；UNNEST 数组参数（15 种元素类型白名单）；事务级 Advisory Lock 四扩展方法（阻塞/非阻塞、long 键/双 int 键，`AdvisoryLockExtensions.cs`）；LISTEN/NOTIFY 后台监听器（重连退避 + 抖动、30s 心跳保活、零分配事件分发，`PgNotificationListener.cs`）；pgvector 文本边界路线（`VectorText.cs`，写入 `::vector` cast、读取 `::text` 解析，AOT 兼容）；JSON 路径查询 `WhereJson`（`PostgreSqlExtensions.cs`） |
| MySQL | 驱动 `MySqlBulkCopy`（列映射缓存、告警检查防静默截断、超时透传，`MySqlBulkCopyInserter.cs`）；local_infile 三层降级（探测缓存 → BulkCopy 失败强制重探测 → 多值 INSERT 回退）；8.0.19+ `UPDATE JOIN VALUES ROW` 形态版本探测；`EntityDataReader` 实体列表的 DbDataReader 包装（供 BulkCopy 消费） |
| SQLite | SQLite3MC 驱动支持 AES-256 静态加密（连接串 `Password=` 启用，驱动层能力）；PRAGMA 调优组（WAL / synchronous=NORMAL / mmap / cache_size，内存库与只读库窄分支）；池化句柄 PRAGMA 记忆（每物理连接一次，`foreign_keys` 每会话重设）；瞬时故障 BUSY/LOCKED 重试 |

三方言共同的连接串自动调优：仅当连接串未显式给出且值为驱动默认时才覆盖（池参数、AutoEnlist、PG `MaxAutoPrepare=100`、MySQL `AllowLoadLocalInfile` 等），见各 Provider 的 `CreateConnection`。

## 12. 配置系统（DbOptions）

`src/PalORM.Core/DbOptions.cs`，sealed record（init-only，`ToString` 自动脱敏连接串与会话 SQL）：

- **三预设**：`Development`（宽松超时、熔断禁用）/ `Production`（严格超时、重试 5、Process 级熔断、池 100、支持副本）/ `Testing`（短超时、零重试）。
- **环境变量装配**：`FromEnvironment` 读 `PALORM_CONNECTION` / `PALORM_READ_CONNECTION` / `PALORM_COMMAND_TIMEOUT` / `PALORM_CONNECTION_TIMEOUT` / `PALORM_MAX_RETRIES` / `PALORM_CIRCUIT_BREAKER_THRESHOLD` / `PALORM_MAX_POOL_SIZE`，组装后立即 Validate。
- **连接串环境引用**：`$ENV:VAR` 形态，`ResolveConnectionString` 运行时解析。
- **主要配置项**：连接/命令超时、`MaxRetries` + `RetryBackoff`（默认指数 100ms 起步 + 50%~100% 抖动）、`OverallDeadline` 总预算、池四参数（MaxPoolSize/MinPoolSize/IdleTimeout/Lifetime）、熔断三参数（阈值/冷却/作用域）、`QueryCache`（自定义缓存实现）、`SessionSetupSql` / `ReadSessionSetupSql`（主/副本连接首激活一次性执行）、`ValidateQueryColumnOrder`、`Interceptors`、`LoggerFactory`。

## 13. 测试生态与工具

- **PalORM.Testing 包**：`TestDb.SqliteAsync()` 内存库三行集成测试（零 Docker）；PG/MySQL 连接串双层解析（环境变量 > `appsettings.test.json` 模板，`.env.test` 只补缺失键），配置缺失显式失败不静默回退（`TestEnvironment.cs`，STJ 源生成保持 AOT 兼容）。
- **Scaffold 脚手架**（`tools/PalORM.Scaffold`，仓库内工具）：三方言 schema 反向生成 PalORM 实体类，snake_case → PascalCase，自动加 `[Column]`/`[Key]`/可空注解（`#nullable enable` 驱动生成物 IsDBNull 守卫），每表一个文件或 stdout。
- **性能工具链**（仓库内，不入 NuGet 发布面）：`bench/` 三臂基准（ADO.NET / Dapper / PalORM 同批对照，SQLite/PG/MySQL 真库）；`tools/PalORM.PerfCli`（性能批次采集）/ `PalORM.PerfGate`（门禁与四组表报告）。
- **AOT 验证链**：`test/PalORM.AotTest*` 三个独立发布工程做三方言全链路发布验证。

## 14. 能力边界（代码里的硬边界）

| 能力 | 状态 | 位置 |
|------|------|------|
| 嵌套事务 | 不支持，重复开启抛异常 | `DataSession.Transactions.cs` 的 `BeginTransactionAsync` |
| `Select()` 投影接实体执行 | 仅 DryRun/ToSql 可用，实体执行明确失败 | `QueryBuilderExtensions.cs` |
| `[Schema]` / `[Database]` 注解 | PALORM011 编译期拒绝 | `PalORMAnalyzer.cs` |
| 增量 ALTER 迁移 | 不做，MigrateAsync 是幂等新建哲学 | `MigrationEmitter.cs` |
| UNION / INTERSECT 集合运算 | 不支持 | `SqlSets.cs` 实为方言 SQL 集而非集合运算 |
| 写路径自动重试 | 不做（仅连接与只读查询内置；幂等契约由调用方保证） | `DbOptions.cs` 的 `MaxRetries` 文档 |
