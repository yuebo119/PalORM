## I. AI 协作 6 条铁律（不可违反）

| # | 铁律 | 违反后果 |
|---|------|---------|
| 1 | **同类改动批量完成后一次构建** | 过度等待或缓存掩盖断裂 |
| 2 | **批量 Edit 前必 Read** | 锚点漂移 |
| 3 | **SuppressMessage 必附 Justification** | 无依据抑制 |
| 4 | **Partial 拆分每个文件 using 独立确定** | CS0246/CS0103 |
| 5 | **字符串拆行不可简单 split** | 语法断裂 |
| 6 | **测试凭据不用硬编码** | 安全警告 |

## IV. 精炼 SOP

### 阶段 1：调研
Agent 并行调研 → 文件清单 + 职责评估 + 评级 → ROI 排序

### 阶段 2：执行
D 删除（低风险）→ M 合并（低）→ R 拆分（中高，每个独立提交+测试）

### 阶段 3：验证
全量构建 → 全量测试 → grep 残留
