## 6. 环境与形态注记

- Windows 10 x64；容器 MySQL 8.4.11@3306（local_infile=ON）/ PG 18.6@55432（pgbench 容器）；
- MySQL 臂驱动差异：linq2db/MySql.Data（镜像缺 linq2db.MySqlConnector）、NHibernate/MySqlDataDriver（5.6 无 MySqlConnectorDriver）——报告注记不剔除；

- 文档臂（Marten/LiteDB）为 jsonb/文件存储，无 SQL 同表位，读族数值量级不可与 SQL 臂直接比；
- NHibernate 实体=臂内 virtual POCO + 每操作转换；EF=每操作 DbContext；均为官方推荐形态，成本含在测量内。
